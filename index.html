Job Overview

At BeeSafe AI, our mission is stopping scams before they reach customers. As an Application Security & Systems Research Engineer, you will operate at the intersection of web runtime security, API isolation, software fuzzing, and cryptographic boundary defense.

You will collaborate with world-class engineers and AI researchers to probe application vulnerabilities, architect defensive runtime primitives, and build automated verification systems protecting millions of user interactions.

Key Responsibilities

  • Conduct in-depth application security reviews, threat modeling, and differential fuzzing across customer-facing and backend APIs.
  • Architect automated threat detection instrumentation, secure sandboxing, and runtime application self-protection (RASP) mechanisms.
  • Develop proof-of-concept exploits and defensive mitigations to protect microservices and cloud workloads against adversarial scam automation.
  • Author high-fidelity security RFCs, architectural standards, and technical research, representing BeeSafe AI at premier cybersecurity summits.

Qualifications & Experience

Minimum Qualifications

  • Bachelor’s, Master’s, or equivalent practical experience in Computer Science, Cybersecurity, or related STEM discipline.
  • Demonstrated proficiency in low-level systems programming languages (C/C++, Rust) and scripting/automation with Python.
  • Solid understanding of Linux kernel internals, virtual memory management, system calls, and network protocol stacks (TCP/IP, TLS).

Preferred Qualifications

  • Experience with eBPF, secure enclave technology (Intel SGX, AWS Nitro Enclaves), or hypervisor virtualization primitives.
  • Prior contributions to open-source security tools or recognized vulnerability disclosures (CVEs).
